# NoMoreClass public static archive

This archive contains the publicly accessible HTML pages listed in the site's public sitemap, along with same-domain CSS, JavaScript, images and fonts referenced by those pages.

It does not include WordPress/PHP source code, databases, admin/login pages, private files, or the backend used for forms and dynamic features.

To preview locally, serve this folder with a static HTTP server and open the root URL. First-party absolute URLs were made root-relative, so assets resolve when served from this directory.

Some old image-thumbnail URLs returned 404 or 422 from the original server and cannot be included.
